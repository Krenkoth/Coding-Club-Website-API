# Coding Club Website API

Backend for Woodinville High School Coding Club Website, linked [here](https://github.com/Krenkoth/Coding-Club-Website).

### Features

- Create user accounts with emails
- Respond to GET requests for users
- Respond to GET requests for projects

### Implementation

- Used NodeJS for backend
- Used MongoDB for a database
- Used a variety of servers to host the code
